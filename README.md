# Твой пост на сегодня — Telegram Mini App

Статическая мини-игра по макетам 390 × 844. Девять зон нажатия совпадают с изображением клавиш, каждая открывает свою плашку. Кнопка 9 запускает золотые конфетти. Плашку можно закрыть и повторять выбор без ограничения попыток.

## Файлы для GitHub Pages

Загрузите **содержимое этой папки** в корень репозитория:

```text
index.html
assets/
  buttons.png
  exit-black.svg
  exit-grey.svg
```

В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`. Получившийся адрес вида `https://имя.github.io/репозиторий/` откройте на телефоне и проверьте все девять кнопок.

После публикации URL можно указать как Web App URL в `@BotFather`. Создание и обновление бота — отдельный следующий этап. Эта версия не использует сервер, базу данных и ключи бота. Верхний крестик закрывает Mini App через Telegram WebApp API; при обычном открытии страницы в браузере он возвращает назад, если есть предыдущая страница.

## Редактирование

Тексты уведомлений находятся в массиве `messages` в конце `index.html`: один элемент массива соответствует одной клавише, а каждый вложенный элемент — точной строке плашки. Фон задан цветом `#1B1B1B`. PNG и SVG из исходных файлов лежат в `assets/` без перерисовки.

Макет задаёт вертикальные отступы для экрана 390 × 844, а по ширине масштабируется для более узких телефонов. Для идеального совпадения шрифта нужен исходный файл гарнитуры, если в дизайне использовался не Arial.
